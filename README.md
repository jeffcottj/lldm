# LLDM

LLDM is a living-room role-playing game designed around an LLM-powered game
runner, a TV-based shared presentation, physical dice for dramatic moments,
and phone-based player interaction.

The project is currently in the planning and rules-design phase. The primary
implementation plan is in [PRIMARY_PLAN.md](PRIMARY_PLAN.md), and the project
principles are in [AGENTS.md](AGENTS.md).
