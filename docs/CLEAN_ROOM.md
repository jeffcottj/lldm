# LLDM Clean-Room Policy

## Purpose

LLDM's rules names, prose, examples, fictional fragments, and game content must be original. Familiar genre ideas may inspire broad goals, but no existing tabletop game is a source for LLDM expression or a collection to adapt.

## Permitted sources

- Original design and writing created for LLDM.
- General facts, public-domain material, and broad genre conventions that are not copied in their distinctive expression.
- Official technical documentation for programming languages, libraries, file formats, hosting platforms, and development tools. Technical documentation may guide implementation, but its prose does not become game rules or content.
- Third-party audiovisual assets only when a future asset record captures the exact source, compatible license, required attribution, and any modifications before the asset enters the product.

## Prohibited use

Do not copy, lightly rewrite, translate, or closely adapt rules prose, stat blocks, worked examples, terminology collections, character options, setting lore, maps, or other expressive content from an existing tabletop game or related publication. Do not use such a publication as a checklist whose distinctive selection and arrangement is reproduced under new labels.

No claim that content is "common," "inspired by," or privately used overrides this policy.

## Review step

Before accepting new rules, examples, or content:

1. Confirm that the author created the names, phrasing, scenario details, and combination of elements for LLDM.
2. Compare the contribution with the executable contracts and generated reference so prose does not introduce an unvalidated mechanic.
3. Check that examples use LLDM terminology and newly created characters, places, and situations.
4. For any third-party audiovisual asset, verify its future license-and-attribution record before use.

When origin is uncertain, stop using the material. Record the uncertainty in the review, replace it with independently written material, or obtain explicit compatible permission before continuing. Removing questionable wording is preferable to trying to disguise its source.

Phase 0 does not require a per-change provenance ledger. Review evidence may live in the normal change discussion until a later asset manifest or content workflow requires a dedicated record.
